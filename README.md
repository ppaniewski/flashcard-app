# Flashcard App
A simple flashcard study tool built with **Node.js**, **Express**, **MongoDB**, and **JavaScript** designed to create and review custom flashcard sets.

## Features
- Create, edit, and delete custom flashcard sets
- Practice all cards or only the ones you got wrong
- Mark flashcards as correct or incorrect
- Authentication system with JWT and cookies
- Persistent data storage using MongoDB via Mongoose
